## Versionamento e publicação

A documentação integra o repositório desde 10 de outubro de 2026.
O GitHub Pages recebe somente static/.
Versionar um documento não o adiciona às páginas do currículo.
O clone reproduz os arquivos versionados, sem credenciais, processos ativos ou arquivos excluídos do Git.
Os currículos e certificados integrais permanecem fora do projeto.

## Referências locais

Os seis PDFs privados do acervo inicial não acompanham clones.
As cópias comerciais em referencias/ats/originais-local/ também permanecem excluídas do Git.
Os clones completos dos dois guias editoriais permanecem em referencias/ats/repositorios-local/, também excluídos do Git.
O [manifesto dos guias](referencias/ats/manifesto-fontes-editoriais-2026-10-13.json) registra commits, licenças e hashes para recuperação.
O guia reúne as [condições de obtenção](referencias/guia-de-uso.md#conferir-os-originais) e as [condições comerciais](referencias/guia-de-uso.md#licenças-e-cópias-comerciais).
Os manifestos preservam origens, tamanhos e hashes SHA-256.

1. Obtenha cada referência conforme suas condições de uso.
2. Solicite uma cópia autorizada ao responsável quando necessária.
3. Salve o arquivo no caminho registrado no manifesto.
4. Compare o tamanho e o SHA-256 antes de usar a cópia.
