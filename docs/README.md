## Versionamento e publicação

Desde 10 de outubro de 2026, a documentação integra o repositório no GitHub.
Essa decisão substitui a regra anterior de manter toda a pasta apenas localmente.
O GitHub Pages continua recebendo somente `static/`.
Versionar um documento não o adiciona às páginas do currículo.
Documentos versionados podem ser consultados e baixados diretamente no GitHub.

Alguns PDFs permanecem locais por restrição de reprodução ou por conter identificadores de terceiros.
O `.gitignore` define essas exceções específicas.
Os manifestos preservam as fontes, os tamanhos e os hashes das cópias recebidas.
Os arquivos originais não foram editados para esta publicação.
Os currículos e certificados integrais permanecem fora do projeto.

O clone reproduz o código e os documentos versionados.
Ele não transporta credenciais, processos ativos ou arquivos excluídos do Git.
Consulte as instruções de recuperação para completar as referências locais.
