## Aplicação ao currículo

O perfil Europass reúne experiências, formação e competências para produzir currículos selecionados conforme a candidatura.
As orientações oficiais recomendam destacar experiências relevantes, usar linguagem clara, revisar o texto e apresentar a experiência em ordem cronológica inversa.
O histórico completo serve como base de consulta. A candidatura deve destacar os fatos pertinentes à oportunidade.

Para este projeto, mantenha os currículos gerais V3 como acervo completo.
Prepare versões direcionadas quando uma candidatura exigir outro foco ou extensão.
Use o editor Europass quando a oportunidade solicitar esse formato.
Os PDFs V3 deste repositório são documentos próprios. Eles não foram exportados pelo editor Europass.

A página de criação de CV sugere fotografia. As condições da vaga e do destino devem orientar essa decisão.
O uso do Europass não comprova reconhecimento de diploma, equivalência profissional ou compatibilidade universal com ATS.
