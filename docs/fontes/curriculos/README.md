## Recuperação

1. Acesse cada URL do manifesto com a conta autorizada.
2. Baixe o arquivo original, sem conversão.
3. Salve o arquivo em originais-local/ com o nome registrado.
4. Confira o tamanho e o SHA-256 com o manifesto.
5. Execute git check-ignore para confirmar a exclusão do arquivo.

Esses arquivos não acompanham clones do projeto.
O [guia de uso](../../referencias/guia-de-uso.md#currículos-originais) centraliza as condições de manutenção.
