## Manutenção

Os três conjuntos HTML devem conter os mesmos 17 cursos, títulos, instituições, cargas horárias e datas. A impressão deve apresentar cada curso uma única vez, com a lista de tela aberta ou fechada.

As demais versões linguísticas e os currículos em DOCX/PDF permanecem como edições anteriores. As cópias oficiais e os originais não foram alterados. Para uma nova exportação de currículo em português brasileiro, use os dados atualizados da página e este registro.
