O arquivo compactado preserva falhas e resultados positivos. Nenhuma evidência foi descartada por apresentar um resultado negativo.

## Consultar um registro anterior

1. Abra o ZIP com uma ferramenta de arquivos compactados.
2. Localize o registro pelo caminho da tabela.
3. Extraia o registro para uma pasta de consulta.
4. Compare o SHA-256 com o manifesto.

As fontes, licenças, dicionários, declarações e clones locais permanecem no acervo existente.
Os 14 arquivos traduzidos de Lista_de_tags são recursos solicitados, não resíduos de execução.
