# Lista geral de tags

O responsável escolheu manter uma lista única para consulta e inclusão nos blocos ocultos.
O nome Lista_de_tags foi solicitado pelo responsável.

[Lista geral com alfabeto latino](lista-geral-alfabeto-latino.txt) contém uma cópia textual dos dados públicos do bloco oculto pt-BR.
A cópia foi criada em 14 de outubro de 2026. Ela preserva as tags portuguesas e os termos ingleses revisados.
As demais traduções ainda não foram acrescentadas.

As instruções de leitura aparecem no início do TXT e no início do bloco oculto, depois do nome do candidato.
Essa posição no HTML preserva a identificação do candidato pelos parsers públicos testados.
As instruções orientam ferramentas que conseguem interpretá-las. Elas não alteram as regras de um parser determinístico.

## Manutenção

1. Acrescente cada nova competência ao final do grupo correspondente.
2. Preserve o contexto pessoal, acadêmico ou do projeto.
3. Preserve as qualificações em cada idioma.
4. Acrescente somente traduções e aliases revisados.
5. Ao enviar a lista para uma página, inclua as instruções de leitura.
6. Atualize a cópia de consulta quando o conteúdo publicado mudar.
7. Confira os dados extraídos antes de publicar a alteração.

Cada página estática mantém sua cópia do conteúdo. Alterar este TXT não atualiza o HTML automaticamente.
Esta pasta fica fora de static/ e não integra o site publicado.

A verificação de 14 de outubro de 2026 foi repetida após o commit 9f2b37f.
Após incluir a tag PID, o bloco oculto contém 187 ocorrências de tags e 168 rótulos distintos.
A cópia TXT corresponde ao conteúdo atual do bloco, com as instruções antes da identificação.
O [registro da verificação](../docs/verificacao-lista-geral-tags-2026-10-14.json) inclui entradas, saídas e limites dos parsers.
